# Beat Lab

A beat-making app for young producers. Open `index.html` in any web browser (no install needed).

- **Missions**: 9 short lessons, from the kick-drum "heartbeat" up to building a full soundtrack.
- **Studio**: a 16-step grid for drums, bass and melody, with 5 moods (scales) and 4 melody sounds.
- **Beat Code**: the same beat written as code. Edit it, press Run, and hear the change.
- **My Soundtrack**: type what the song is for, pick a mood, and it builds an intro, verse, chorus and outro. Save your own beats into slots A to D and arrange them.

All sounds are made live with the Web Audio API. Progress saves in the browser.
